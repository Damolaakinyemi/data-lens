# Data Lens

**An AI-powered economic research copilot** that helps users go from raw data → research-grade insight.

Upload datasets, explore trends with interactive charts, forecast future values, and generate polished summaries suitable for class, papers, and portfolio use.

---

## Features

- Upload CSV and Excel files
- Auto-detect column types (number, date, category)
- Interactive charts: line, bar, area, scatter, pie
- AI-style insight engine with Simple and Academic explanations
- Forecasting with Moving Average, Linear Regression, and Exponential Smoothing
- Best / expected / worst-case forecast bands
- Professional research report with print-to-PDF and copy-to-clipboard

---

## Tech Stack

- Next.js (App Router) + React + TypeScript
- Recharts for visualizations
- PapaParse for CSV parsing
- SheetJS (xlsx) for Excel parsing
- Client-side data workflow (no backend required for MVP)
